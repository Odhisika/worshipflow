# WorshipFlow Pro - User Guide

## 🚀 Getting Started

### First Time Setup

1. **Launch the Application**
   ```
   npm run tauri dev  (for development)
   or
   Double-click the WorshipFlow Pro icon (installed version)
   ```

2. **Add Your First Song**
   - Click "Song Library" in sidebar
   - Click "➕ Add Song"
   - Enter song details
   - **Important**: Separate verses with double line breaks
   - Click "Create Song"

3. **Start Your First Presentation**
   - Click "🎬 Present" on any song
   - Click "▶️ Start Presentation"
   - Use Space bar to advance slides
   - Press ESC to stop

## 📚 Main Features

### 1. Dashboard
- View statistics (songs, services)
- Quick actions
- Development progress

### 2. Song Library
**Add Songs:**
- Title, lyrics, musical key, tempo
- Tags for organization
- Search by title or lyrics

**Manage Songs:**
- Edit existing songs
- Delete songs
- Search and filter
- Load directly to presentation

**Lyrics Format:**
```
Verse 1 lyrics here
All lines of verse 1

Verse 2 lyrics here
All lines of verse 2

Chorus lyrics here
Repeat as needed
```

### 3. Service Planning
**Create Services:**
- Service date and title
- Theme (optional)
- Notes

**Add Activities:**
- Activity name
- Duration in minutes
- Leader assignment
- Notes/instructions
- Use quick templates

**View Timeline:**
- See all activities in order
- Total service duration
- Leader assignments

### 4. Presentation Control

**Loading Content:**
1. Select song from dropdown
2. Click "Load Song"
3. Or load from Song Library

**Controls:**
- **Start**: Begin presenting
- **Stop**: End presentation
- **Next**: Advance slide
- **Previous**: Go back
- **Blank**: Black screen

**Preview Panels:**
- **Current Slide**: What's showing now
- **Next Slide**: What's coming up

**Output Window:**
- Click "📺 Output Window" to open
- Displays slides fullscreen
- Move to projector screen

## ⌨️ Keyboard Shortcuts

### During Presentation
- **Space** or **→ Right Arrow**: Next slide
- **← Left Arrow**: Previous slide
- **B**: Toggle blank screen (black)
- **ESC**: Stop presentation

### Tips
- Works when presentation control is focused
- Don't work when typing in input fields
- Output window receives updates automatically

## 📋 Common Workflows

### Sunday Morning Service

**Before Service:**
1. Add all songs to library
2. Create service in Service Manager
3. Add activities with times
4. Test each song in presentation

**During Service:**
1. Load first song
2. Start presentation
3. Open output window to projector
4. Use keyboard to advance
5. Blank screen during sermon
6. Load next song when needed

### Midweek Bible Study

**Setup:**
1. Add any songs needed
2. Create text slides for verses
3. Pre-load in order

**During Study:**
1. Start presentation
2. Advance through content
3. Use blank for discussions

## 🎨 Tips & Tricks

### Song Lyrics Best Practices
✅ **Do:**
- Use double line breaks between verses
- Keep verses reasonable length
- Test display before service
- Have complete lyrics

❌ **Don't:**
- Use single line breaks only
- Make verses too long
- Include chord notations in lyrics
- Forget copyright notices

### Presentation Tips
✅ **Do:**
- Test on actual projector first
- Practice keyboard shortcuts
- Load songs in advance
- Use blank screen between items

❌ **Don't:**
- Wait until last minute
- Skip rehearsal
- Close output window accidentally
- Forget to start presentation

### Service Planning Tips
✅ **Do:**
- Set realistic activity durations
- Assign leaders in advance
- Use templates for common services
- Note special instructions

❌ **Don't:**
- Over-schedule activities
- Forget buffer time
- Skip leader assignments
- Leave out important notes

## ❓ Troubleshooting

### Problem: Can't see slides on projector
**Solution:**
1. Open output window
2. Drag to projector screen
3. Make sure presentation is started

### Problem: Keyboard shortcuts not working
**Solution:**
1. Click on presentation control window
2. Make sure not typing in input field
3. Check if presentation is live

### Problem: Song not loading
**Solution:**
1. Check song has lyrics
2. Verify song ID is correct
3. Try refreshing song library
4. Restart application if needed

### Problem: Output window won't open
**Solution:**
1. Check if already open (taskbar)
2. Close and reopen
3. Restart application
4. Check for errors in console

## 📖 Glossary

**Slide**: Single screen of content (verse, chorus, etc.)

**Presentation**: Collection of slides ready to display

**Output Window**: Window showing slides on projector

**Control Window**: Main interface for operators

**Service**: Planned worship service with activities

**Activity**: Individual segment of service (prayer, song, etc.)

**Blank Screen**: Black screen with no content

**Live**: Presentation is active and displaying
