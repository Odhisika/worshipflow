## 🚀 Quick Start (3 Commands)

### Prerequisites:
- **Node.js** 18+ ([Download](https://nodejs.org/))
- **Rust** 1.70+ ([Download](https://rustup.rs/))
- **Platform-specific tools**:
  - Windows: Visual Studio C++ Build Tools
  - macOS: Xcode Command Line Tools
  - Linux: build-essential, libwebkit2gtk-4.0-dev, libssl-dev

### Installation:

```bash
# 1. Extract the zip file
unzip worshipflow-pro.zip
cd worshipflow-pro

# 2. Install dependencies
npm install

# 3. Run the application
npm run tauri dev
```

**That's it!** The app will launch and you can start adding songs!

## 🔧 Troubleshooting

### Build Issues:

**"Command not found: cargo"**
- Install Rust: https://rustup.rs/

**"ENOENT: no such file or directory"**
- Run `npm install` first

**"Tauri failed to bundle"**
- Check platform-specific requirements
- Windows: Install Visual Studio C++ Build Tools
- macOS: Install Xcode Command Line Tools
- Linux: `sudo apt install build-essential libwebkit2gtk-4.0-dev libssl-dev`

### Runtime Issues:

**App won't start:**
- Check logs in: `~/.local/share/com.worshipflow.pro/`
- Try: `npm run tauri dev` to see console output

**Database errors:**
- Database is created automatically on first run
- Location: System app data directory
