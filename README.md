## 🎬 How to Use (Simple!)

### 1️⃣ Add Your Songs
```
Song Library → ➕ Add Song → Enter lyrics → Save
(Use double line breaks to separate verses)
```

### 2️⃣ Load to Presentation
```
Click 🎬 Present button → Song loads automatically
Or: Presentation tab → Select song → Load Song
```

### 3️⃣ Start Presenting
```
Click ▶️ Start Presentation
Output window opens on your projector
Use Space bar to advance slides
Press ESC to stop
```

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` or `→` | Next slide |
| `←` | Previous slide |
| `B` | Blank screen |
| `ESC` | Stop presentation |
