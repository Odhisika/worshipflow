🚀 HOW TO RUN
════════════════════════════════════════════════════════════════════════════════

First time setup:
  1. Install Rust: https://rustup.rs/
  2. Install Node.js: https://nodejs.org/
  3. cd worshipflow-pro
  4. npm install

Development:
  npm run tauri dev

Production build:
  npm run tauri build
